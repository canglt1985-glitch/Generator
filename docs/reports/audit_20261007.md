## 🔴 1. Critical Issues (Phải sửa ngay)

### 1.1. Lộ lọt mật khẩu tài khoản Mobifone, Gmail App Password và Bot Tokens trong Git Tracking
* **Vị trí phát hiện:** `backend/data/system_config.json`
* **Triệu chứng lâm sàng:** 
  File `system_config.json` đang được Git theo dõi (tracked) và đã được push lên remote repository. Trong file có chứa:
  * Mật khẩu tài khoản Mobifone: `datasite_password`, `smartw_password` (`Lamtuyen@4321`)
  * Mật khẩu ứng dụng Gmail: `gmail_app_password` (`dbohhdjajrtqjdzd`)
  * Token Bot Telegram & Viber: `telegram_bot_token`, `viber_bot_token_*`
* **Hậu quả nếu không sửa:**
  Bất kỳ ai có quyền truy cập vào repo GitHub (hoặc nếu repo bị vô tình chuyển sang Public) đều có thể xem toàn bộ mật khẩu cá nhân, tài khoản đăng nhập portal Mobifone và chiếm quyền điều khiển bot.
* **Phác đồ điều trị (Cách sửa):**
  1. Thêm `backend/data/system_config.json` vào file `.gitignore`.
  2. Chạy lệnh gỡ file khỏi Git cache: `git rm --cached backend/data/system_config.json`.
  3. Tạo file mẫu `backend/data/system_config.example.json` với các giá trị rỗng/mẫu.
  4. Thu hồi và đổi lại mật khẩu Gmail App Password cũng như đổi mật khẩu portal để triệt tiêu nguy cơ.

* **Triệu chứng lâm sàng:**
  ```python

  ```
* **Hậu quả nếu không sửa:**
  Nếu bảng Whitelist trên Supabase rỗng hoặc hệ thống chưa cấu hình biến môi trường, bot sẽ cho phép bất kỳ ai trên Telegram tra cứu thông tin 412 trạm viễn thông, bao gồm cả mật khẩu khóa số và hợp đồng chủ đất.

  Mặc định từ chối (`return False`) nếu whitelist rỗng, hoặc chỉ cho phép duy nhất Admin ID đã được định danh trước.

## 🟢 3. Điểm Sáng & Đánh Giá Tích Cực (Clean & Secure Areas)
1. **Chống SQL Injection xuất sắc:** Toàn bộ truy vấn dữ liệu được điều phối qua PostgREST của Supabase với tham số hóa (Parameterized queries) an toàn.
2. **HTML Sanitization trong Bot Telegram:** Hàm `escape_html()` được áp dụng nghiêm ngặt trên mọi trường thông tin động trước khi gửi qua Telegram HTML format mode, chống hoàn toàn lỗi Telegram parsing crash.
3. **Phân tách Bundle Frontend (Code-splitting):** Các thư viện dung lượng lớn như `exceljs`, `docx`, `leaflet` được tách riêng, bundle chính chỉ nặng 62KB (gzip 21KB) giúp tải trang cực nhanh.
4. **Cơ chế chống đụng độ tiến trình (Single-Instance Mutex):** Sử dụng loopback TCP port `59123` trong `run_workers.py` ngăn chặn triệt để tình trạng chạy 2 tiến trình worker song song gây spam tin nhắn.
