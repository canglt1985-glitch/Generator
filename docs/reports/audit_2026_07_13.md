- **File ảnh hưởng**:
  * [smartw_worker.py](file:///Users/cang_it/Antigravity/TVT3/backend/smartw_worker.py#L283-L284) (dòng 283, 284, 308, 914, 1132)
  * [fetch_outages.py](file:///Users/cang_it/Antigravity/TVT3/backend/fetch_outages.py#L122) (dòng 122)
  * [daily_report.py](file:///Users/cang_it/Antigravity/TVT3/backend/daily_report.py#L599) (dòng 599)
- **Nguy hiểm**: 
  * Các API token của Viber Bot (như `56a990b99bf464bd-...`, `56b57ae5...`) đang được gõ cứng trực tiếp vào mã nguồn dưới dạng phương án dự phòng (fallback).
  * Nếu mã nguồn này vô tình bị đưa lên GitHub công khai hoặc lọt ra ngoài, kẻ xấu có thể đánh cắp token này để kiểm soát hoàn toàn bot, đọc trộm tin nhắn phản ánh của khách hàng hoặc gửi tin nhắn rác phá hoại hệ thống.
- **Cách sửa**:
  * Chuyển toàn bộ các giá trị API token này vào tệp cấu hình `.env` cục bộ trên máy chủ.
  * Trong code Python, đọc qua `os.getenv("VIBER_TOKEN_OUTAGES")` hoặc tệp cấu hình động `config.json` thay vì ghi cứng.
