## 🔴 Critical Issues (Phải sửa ngay)

### 1. 3 file template Word `MAT_BANG` bị lỗi thẻ XML (mismatch tags)
- **Tập tin liên quan**: `tvt3_v2/public/templates/`
- **Nguy hiểm**: Quá trình sinh file bằng thư viện `docxtemplater` sẽ bị **lỗi crash hoặc lỗi hiển thị trắng** ở phía Client (trình duyệt của người dùng) do số lượng thẻ mở `{{` (67 thẻ) không khớp với số lượng thẻ đóng `}}` (66 thẻ). Điều này khiến người dùng không thể tải xuống văn bản pháp lý hợp lệ.
- **Cách sửa**: 
  - Mở trực tiếp các biểu mẫu Word bị lỗi bằng Microsoft Word, tìm các đoạn tag bị chắp vá (do Word tự chia nhỏ các run XML khi gõ phím) và gõ đè viết lại toàn bộ tag đó liền mạch.
  - Hoặc sử dụng script Python phân tích sâu hơn để tự động vá lại cấu trúc XML của file `.docx`.
